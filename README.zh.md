# dsh-model-manager 中文文档

DeepSeek Harness 的模型服务商管理插件。把服务商连接配置、模型目录、模型别名、推理强度、本地 HTTP 代理、快捷测试、故障切换、用量统计和费用估算集中到一个管理页面。

当前版本：**0.18.0**

完整中文说明以 [README.md](README.md) 为准，本文是同一内容的精简版。

>

>

## 每个服务商一个密钥

连接设置里填写 Base URL、接口协议、密钥变量名和 API Key。密钥由 DSH 凭据服务保存，不写进模型配置。

要给同一个上游模型设置不同价格或名称时，不要新建服务商，使用模型别名。

## 模型别名

展开服务商卡片的“管理”，在“模型别名（本地模型 → 上游模型）”中填写：

```text
分组名称：cheap
本地模型别名：gpt-4o-0.05
上游模型 ID：gpt-4o
```

效果：

- DSH 里出现独立模型 `gpt-4o-0.05`
- 用量和费用按 `服务商/gpt-4o-0.05` 单独统计
- 发给上游时模型名改回 `gpt-4o`
- 仍然使用该服务商自己的那一个密钥

别名里的数字只是名字，不会自动改价，也不切换账户分组。价格请在“用量统计 → 单价”里填写。

移除别名：点别名右侧 `×`，或点“移除分组”。两种方式都会同时删除对应的别名模型，避免留下发不出去的模型。

## 单价：手动添加、排序筛选、删除

单价表里只会出现你自己添加过的模型；用量统计、测试调用、模型目录都不会自动塞条目。

在“用量统计 → 单价（用于估算费用）”中：

- **＋ 添加模型价格**：点按钮 → 选服务商 → 填模型 ID（可从目录选）→ 添加
- **删除**：每行都有“删除”，立即删掉该模型单价并移出列表
- **筛选**：输入框按 `服务商/模型` 过滤；下拉可只看某个服务商
- **排序**：名称 / 服务商 / 输入价高→低 / 输出价高→低 / 最近添加
- **清空**：只清空编辑框内容，仍需点“保存单价”

另外，在服务商的“模型管理”里点某个模型“编辑”，推理档位下面也能直接填价格：输入 / 输出 / 缓存命中 / 缓存写入 + 币种，点“添加价格”或“保存价格”即时写入；已有价格可点“删除价格”。

测试调用（快捷测试 / 诊断 / 压测）不计入费用，也不会产生单价行。

## 推理强度

主代理默认 `high`：没有单独设置时用 `high`；单独设置优先；模型不支持时自动降到最接近档位；完全不支持推理则不发送参数。子代理仍支持统一档位、按模型档位和会话级设置。

## 代理、发现和测试

- 代理按服务商生效，作用于模型调用、快捷测试和模型发现
- 支持自动检测常见端口和手动填写地址
- “获取模型”读取服务商模型目录
- 快捷测试可选择模型和推理程度，并查看状态、错误、耗时和 token
